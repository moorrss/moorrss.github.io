## Om projektet

Den här portfoliosidan skapade jag med hjälp av **vibe coding** – för att snabbt och enkelt få in all information om mig på ett ställe. Istället för att lägga tid på att koda allt från grunden samarbetade jag med AI (Claude) för att bygga sidan, medan jag fokuserade på innehållet om mig och mina projekt.

Sidan presenterar mig som systemutvecklarstudent med inriktning säkerhet och är tänkt för LIA-ansökningar och jobbsökande.

## Mina projekt

###  [KodLabbet](https://github.com/moorrss/KodLabbet-GitHub)
Fullstack webbapplikation för interaktiv kodutbildning. Byggd med ASP.NET Core 9, C# och JavaScript. Inkluderar JWT-autentisering, live kodeditor, dagliga utmaningar och PvP-arenor.

###  [MormorsDB](https://github.com/moorrss/Inl-mningMDB)
Relationsdatabas för ett bageri, byggd från grunden med SQL. Komplex datamodellering med ER-modell, Foreign Keys, JOINs och GROUP BY.

###  [WestCoast EDU](https://github.com/moorrss/WestCoastEDU)
Konsolbaserat administrationssystem i C#/.NET. Hanterar studenter, lärare och kurser med full CRUD-funktionalitet och tydlig lagerarkitektur.

## Vibe coding – hur det fungerade

Jag använde **Claude** som min AI-partner. Målet var enkelt: **snabbt och smidigt få in all info om mig på ett ställe** utan att behöva kunna webbutveckling från grunden.

Jag beskrev vad jag ville ha, gav Claude mitt CV och mina GitHub-länkar, och fick en färdig portfoliosida som jag sedan laddade upp på GitHub Pages. Fokus låg på innehållet – inte på koden.
